# Bucha Alerts Analyzer

Інструмент на Python для збору, обробки та візуалізації статистики повітряних тривог у місті Буча та Бучанському районі.

## Функціонал
* Завантаження даних про тривоги через API або локальні CSV-файли.
* Підрахунок загальної кількості тривог, їх середньої та максимальної тривалості.
* Побудова графіків активності тривог по днях тижня або годинах доби.

## Встановлення та запуск

1. Клонуйте репозиторій:
  
   git clone https://github.com
   cd bucha.alerts-analyzer
   
2. Встановіть необхідні бібліотеки:
  
   pip install -r requirements.txt
   
3. Запустіть скрипт аналізу:
  
   python analyzer.py
